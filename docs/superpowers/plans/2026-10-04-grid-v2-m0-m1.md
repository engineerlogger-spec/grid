# Grid v2: M0 (Foundation) + M1 (Core ledger) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Executor note:** the lead developer executes this plan inline (the owner is offline; no subagents). Pure-domain tasks list their exact test cases (inputs → expected results). Those tests are written first and must fail before the implementation is written. UI tasks list components, state contracts and on-device acceptance checks run with `scripts/ui.ps1`.

**Goal:** A fresh native Android app on branch `v2` that installs as **Grid**. It has the Graphite & Lime design system, onboarding, two-action quick add, a bento Home with the month grid, Activity, and the monthly income check-in. It's backed by a tested Room schema v1.

**Architecture:** Single `:app` module (`com.grid.app`). Compose UI → Hilt ViewModels (`StateFlow` UiState) → repositories → Room / DataStore. Pure-Kotlin domain code (`core/model|money|time|insights`) has no Android imports and is unit-tested on the JVM. Robolectric covers DAOs and repositories.

**Tech Stack:** Gradle 9.8.0, AGP 9.4.1 (built-in Kotlin), Kotlin 2.4.20, KSP 2.3.12, Compose BOM 2026.09.00, Material 3, Navigation Compose 2.10.2, Hilt 2.60.1, Room 2.8.5, DataStore 1.2.1, kotlinx-serialization 1.11.0, JUnit4 + Truth + Turbine + Robolectric 4.17.

## M1: Core ledger

### Task 1.1: Money (TDD)
**Files:** `core/money/Currencies.kt`, `MoneyFormatter.kt`, tests `MoneyFormatterTest.kt`.
API:
```kotlin
object Currencies { fun fractionDigits(code: String): Int; fun defaultFor(locale: Locale): String }
class MoneyFormatter(private val locale: Locale) {
    fun format(minor: Long, currency: String, signed: Boolean = false, masked: Boolean = false): String
    fun parts(minor: Long, currency: String, masked: Boolean = false): MoneyParts  // MoneyParts(whole: String, fraction: String) — whole includes symbol + sign
    fun plain(minor: Long, currency: String): String   // "12.50" for keypad prefill, no symbol, locale-independent '.'
}
```
Tests (Locale.US unless noted):
- [ ] `format(1250, "EUR")` = `€12.50`; `format(123456, "USD")` = `$1,234.56`.
- [ ] `Locale.FRANCE`: `format(123456, "EUR")` = `1 234,56 €` (normalize NBSP/NNBSP to a space in the assertion).
- [ ] `format(1250, "EUR", signed = true)` = `+€12.50`; `format(-1250, "EUR", signed = true)` = `−€12.50` (U+2212).
- [ ] JPY has 0 fraction digits: `format(1200, "JPY")` = `¥1,200`.
- [ ] `masked = true` → `€••••`.
- [ ] `parts(128450, "EUR")` = `MoneyParts("€1,284", ".50")`; JPY → fraction `""`.
- [ ] `plain(1250, "EUR")` = `12.5`, `plain(1200, "EUR")` = `12`; `fractionDigits("XYZ")` = 2 (unknown code fallback).

### Task 1.2: Keypad amount input (TDD)
**Files:** `core/money/AmountInput.kt`, test `AmountInputTest.kt`.
```kotlin
sealed interface KeypadKey { data class Digit(val d: Int); data object DoubleZero; data object Dot; data object Plus; data object Minus; data object Backspace; data object Clear }
data class AmountInput(val expression: String = "", val fractionDigits: Int = 2) {
    fun press(key: KeypadKey): AmountInput
    val valueMinor: Long?      // evaluated expression in minor units; null if empty/invalid
    val isExpression: Boolean  // contains an operator
    companion object { fun fromMinor(minor: Long, fractionDigits: Int): AmountInput }
}
```
Tests:
- [ ] Digits `1,2,Dot,5` → expression `12.5`, valueMinor `1250`.
- [ ] A third decimal is ignored: `1,Dot,2,3,4` → `1.23`.
- [ ] A second Dot in the same operand is ignored; Dot first → `0.`.
- [ ] Leading zeros collapse: `0,0,5` → `5`.
- [ ] `1,2,Plus,3,Dot,2` → `12+3.2`, valueMinor `1520`; `isExpression` true.
- [ ] Operator replaces a trailing operator: `5,Plus,Minus` → `5-`; a trailing operator is ignored in evaluation (`5-` → 500).
- [ ] An operator as the first key is ignored.
- [ ] Subtraction can go to ≤ 0 → valueMinor `0` or negative is reported as-is (the caller validates > 0).
- [ ] Integer part is capped at 9 digits per operand.
- [ ] Backspace removes the last char; Clear empties.
- [ ] `fractionDigits = 0` disables Dot.
- [ ] `fromMinor(1250, 2).expression` = `12.5`.

### Task 1.3: Budget periods + clock (TDD)
**Files:** `core/time/AppClock.kt`, `BudgetPeriod.kt`, test `BudgetPeriodsTest.kt`.
```kotlin
interface AppClock { fun now(): Instant; val zone: ZoneId; fun today(): LocalDate = now().atZone(zone).toLocalDate() }
data class BudgetPeriod(val start: LocalDate, val endExclusive: LocalDate) {
    val length: Int; operator fun contains(d: LocalDate): Boolean
    fun dayNumber(d: LocalDate): Int        // 1-based
    fun daysLeft(today: LocalDate): Int     // includes today; 0 if past the period
    val labelMonth: YearMonth               // startDay ≤ 15 → start's month, else next month
    fun days(): List<LocalDate>
    fun startMillis(zone: ZoneId): Long; fun endMillis(zone: ZoneId): Long
}
object BudgetPeriods { fun periodFor(date: LocalDate, startDay: Int): BudgetPeriod; fun previous(p: BudgetPeriod, startDay: Int): BudgetPeriod; fun next(p: BudgetPeriod, startDay: Int): BudgetPeriod }
```
Tests:
- [ ] `periodFor(2026-10-14, 1)` = [2026-10-01, 2026-11-01), length 31, label 2026-10.
- [ ] `periodFor(2026-10-14, 25)` = [2026-09-25, 2026-10-25), label 2026-10.
- [ ] `periodFor(2026-10-25, 25)` = [2026-10-25, 2026-11-25), label 2026-11.
- [ ] startDay is clamped: `periodFor(2026-02-10, 31)` behaves like 28 → [2026-01-28, 2026-02-28).
- [ ] `dayNumber(2026-10-14)` = 14; `daysLeft(2026-10-14)` = 18 for the October period.
- [ ] `previous` of Oct (day 1) = Sep 1–Oct 1; `next` = Nov 1–Dec 1.
- [ ] Year boundary: `periodFor(2027-01-05, 25)` = [2026-12-25, 2027-01-25).

### Task 1.4: Dashboard calculator (TDD)
**Files:** `core/insights/Dashboard.kt`, test `DashboardCalculatorTest.kt`.
```kotlin
data class LedgerEntry(val type: TxType, val amountMinor: Long, val categoryId: Long, val date: LocalDate)
data class DayCell(val date: LocalDate, val state: DayState, val spentMinor: Long, val ratio: Float)  // DayState: PAST, TODAY, FUTURE; ratio = spent / dailyAllowance (0 if no goal)
data class CategoryShare(val categoryId: Long, val amountMinor: Long, val fraction: Float)
data class DashboardSummary(val spentMinor: Long, val incomeMinor: Long, val goalMinor: Long?, val leftMinor: Long?, val perDayMinor: Long?, val days: List<DayCell>, val topCategories: List<CategoryShare>, val dayNumber: Int, val daysLeft: Int, val length: Int)
object DashboardCalculator { fun summarize(period: BudgetPeriod, today: LocalDate, goalMinor: Long?, entries: List<LedgerEntry>, topN: Int = 3): DashboardSummary }
```
Tests (October period, today = Oct 14, goal 310000):
- [ ] Spent = sum of EXPENSE, income = sum of INCOME; left = goal − spent; perDay = left / daysLeft (floor), and 0 if left ≤ 0.
- [ ] `goalMinor = null` → left/perDay null and every ratio 0.
- [ ] days: 31 cells, Oct 14 = TODAY, Oct 15+ = FUTURE, ratio = daySpent / (goal / length).
- [ ] topCategories: sorted desc, only expenses, fractions sum to 1 across all categories (top N returned).
- [ ] Entries outside the period are ignored.
