# Live Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep Grid's bank data close to real time and act on it:
- present-mode syncs that the background limit doesn't apply to
- a sync 5 seconds after each payment notification, with retries
- pull to refresh, and "Updated … ago"
- real payment times
- a Pending tag
- a check notification after each payment, with bill, unusual-amount and double-charge findings

**Architecture:**
- `LiveSync` (core/bank) is the single entry point for every sync. It runs `BankSync.run(mode)`, then posts the check after paying, runs Gemini's tidy-up and the low-funds check, and exposes a `syncing` flow.
- `BankSyncWorker` carries the mode and the retry attempt.
- Pure rules live in `BankTime` (core/bank) and `PaymentChecks` (core/insights).
- `PaymentCheckNotifier` (core/notify) composes and posts the check notification.
- `RefreshViewModel`, `BankRefreshBox` and `BankUpdatedLine` (feature/common) give Home and Activity pull to refresh and the "Updated" line.

**Tech Stack:** Kotlin, Compose Material 3 (`PullToRefreshBox`), Hilt, Room (no schema change), DataStore, WorkManager, OkHttp, Robolectric, Truth.

Spec: `docs/superpowers/specs/2026-10-06-live-sync-design.md`.

```kotlin
object BankTime {
    private val TIMED_ID = Regex("""([0-9a-f]{8})-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}""")
    fun fromId(externalId: String, date: LocalDate, zone: ZoneId): Long? {
        val hex = TIMED_ID.matchEntire(externalId.substringAfterLast(':'))?.groupValues?.get(1) ?: return null
        val instant = Instant.ofEpochSecond(hex.toLong(16))
        return instant.toEpochMilli().takeIf { abs(ChronoUnit.DAYS.between(date, instant.atZone(zone).toLocalDate())) <= 1 }
    }
    fun dayOnly(date: LocalDate, zone: ZoneId, now: Long): Long {
        val noon = date.atTime(LocalTime.NOON).atZone(zone).toInstant().toEpochMilli()
        return if (noon <= now) noon else date.atStartOfDay(zone).toInstant().toEpochMilli()
    }
    fun isDayOnly(at: Long, zone: ZoneId): Boolean =
        Instant.ofEpochMilli(at).atZone(zone).toLocalTime().let { it == LocalTime.NOON || it == LocalTime.MIDNIGHT }
}
```
- **`toEntity`:** `occurredAt = BankTime.fromId(externalId, date, clock.zone) ?: BankTime.dayOnly(date, clock.zone, clock.millis())`.

  - wrap both in `db.withTransaction`
- **`TransactionRow`:** add the time when `showTime` is on, unless `tx.source == BANK && BankTime.isDayOnly(tx.occurredAt, ZoneId.systemDefault())`.
